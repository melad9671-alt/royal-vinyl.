# Offline Music Player

A native Android music player rebuilt using Kotlin and Jetpack Compose.

Included baseline: on-device audio scanning through MediaStore, local playback using AndroidX Media3 ExoPlayer, local title/artist search, favorites saved on-device, and the Royal Vinyl black/soft-purple visual identity. Movies is marked Coming Soon.

GitHub Actions builds a debug APK on pushes to the offline-music-player branch. The artifact is named Offline-Music-Player-debug.
